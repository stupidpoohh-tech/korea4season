# 지금 산 — 예측 탐색 개선 (2026-10-08)

## 바뀐 동작
- 모바일 예측 장소·날짜 보기 시트와 데스크톱 레일이 같은 전체 수종별 목록을 사용한다. 7일 뒤보다 먼 예측도 숨기지 않는다.
- 위치 미연결 장소도 날짜를 확인하고 예측일로 이동할 수 있다. 위치를 추정해 지도에 올리지 않는다.
- 연결된 장소를 선택하면 재생을 멈추고 지도 위치를 강조한다. 지도 지점도 클릭·키보드로 선택할 수 있다.
- 지점은 예측일 전(빈 점), 선택 날짜가 예측일인 경우(주황), 지난 예측일(회색)로 구분한다. 현재 단풍 상태를 뜻하지 않는다.
- 상단에 실시간 현황이 아님을 표시하고, 목록에 발행처·원문 확인 중임을 밝힌다.
- 모바일 날짜 컨트롤을 펼치면 기본 약 7초 / 천천히 약 28초 재생을 선택할 수 있다. 데스크톱에는 항상 보인다.
- 가을 예측 패널이 여름에도 나타나거나 마지막 예측일 직후 여름 문구로 바뀌던 조건을 수정했다.

- 시작일·끝물·현재 단풍률을 새로 추정하지 않는다.

- 현재 상태 지도와 예측 일정의 제품적 역할 구분은 추가 결정이 필요하다.
